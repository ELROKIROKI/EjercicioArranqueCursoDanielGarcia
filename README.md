# Gestor de tareas en Java

Programa sencillo de consola para gestionar una lista de tareas.

## Funciones

- Añadir tareas.
- Ver las tareas guardadas.
- Marcar tareas como completadas.
- Eliminar tareas.
- Guardar hasta 10 tareas.

## Tecnologías utilizadas

- Java
- `Scanner` para leer datos introducidos por el usuario.
- Arrays para almacenar las tareas y su estado.

## Cómo ejecutarlo

1. Guarda el código en un archivo llamado `Main.java`.
2. Compílalo:

```bash
javac Main.java
```

3. Ejecútalo:

```bash
java Main
```

## Ejemplo del menú

```text
--- GESTOR DE TAREAS ---
1. Añadir tarea
2. Ver tareas
3. Completar tarea
4. Eliminar tarea
0. Salir
```

## Nota

Las tareas solo se guardan mientras el programa está abierto. Al cerrarlo, se pierden.
